# Security Policy

## Supported Versions

We actively support security updates for the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

PowerShell command history frequently contains sensitive data such as API tokens, session cookies, passwords, or internal URLs.

If you discover a security vulnerability or sensitive data handling flaw:
1. **Do not** open a public GitHub issue.
2. Please report the security finding privately by opening a [GitHub Security Advisory](https://github.com/eloqven/powershell-history-navigator/security/advisories/new) or contacting the maintainers directly.
3. We will acknowledge receipt within 48 hours and work with you on a timely resolution.
